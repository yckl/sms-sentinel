# 重要短信哨兵（Android）V1.4.1

只监听一个指定号码，把**含关键词的会议短信**变成一次“来电式”全屏提醒：**接听 = 确认并阅读，挂断 = 确认但未阅读**；不操作则按间隔再次响起，直到确认。

界面按 iOS 27 的方向重做：大标题、分组白卡、悬浮胶囊底栏、iOS 系统色；应用图标使用 `tubiaoui.png`。

V1.3 视觉打磨：环境光渐变背景；蓝色状态卡的玻璃高光与柔和阴影；设置项彩色图标瓦片；提醒记录按“今天 / 昨天 / 日期”分组；底栏切换淡入和触感反馈；来电页脉冲环动效。

设计与交互基线见上级目录的 `重要短信哨兵_产品设计方案_V2.0_来电式.docx`。V1.1 在此基础上的变更是：**增加会议关键词过滤**、**常驻后台监听服务**、**应用内顶部来电横幅**。

## 已实现

- 唯一号码监听（默认 `10650821192421`，可在设置中修改），只按来源号码匹配。
- **会议关键词过滤**：默认 `会议,开会,参会,议程,会场`，只提醒命中关键词的短信；可在设置中编辑，或关闭过滤提醒全部短信。
- 短信广播接收、多段短信拼接、重复广播去重。
- 来电式全屏提醒：深色大屏、来源号码、正文（锁屏默认隐藏）、接听/挂断双按钮。
- **应用内顶部来电横幅**：App 在前台时，新会议短信从顶部滑入，可直接接听/挂断。
- 接听：先通过系统解锁，再标记“已确认 · 已阅读”，停止提醒并打开详情。
- 挂断：标记“已确认 · 未阅读”，停止提醒，记录中可恢复为待确认。
- 返回键/手势、响铃超时、划掉通知都不确认，任务保持待确认。
- 10 分钟循环提醒（5/10/15/30/60 分钟可配），每次响铃 30/45/60 秒可配。
- AlarmManager 精确闹钟；无精确权限时自动降级为非精确调度。
- 全屏不可用时降级为高优先级通知（Android 14+ 不再使用无全屏 Intent 的 CallStyle），接听/挂断按钮仍可用。
- **前台监听服务**：保持进程存活，降低“第一次能弹、后面不弹”的概率；重启后尝试自动恢复。
- **静音/勿扰下仍然震动**：震动由 App 直接驱动，不受系统静音或勿扰拦截；关闭铃声只保留震动也有效。
- **通知兜底**：锁屏时即使厂商拦截了全屏页面，通知本身也会响铃/震动，不会出现“检测到但没反应”。
- **小窗直接操作**：亮屏使用中，通知按钮“挂断确认”会直接在后台完成确认（提示“已确认（未阅读）”），不需要打开 App；接听才进入详情页。
- **锁屏唤醒测试**：权限页提供 8 秒倒计时测试；首页在缺少全屏权限时显示橙色警告和“去开启”。
- 通知公开版锁屏脱敏，只显示“重要短信待确认”和来源。
- 正在通话中不弹全屏，改为通知，避免打断系统电话。
- 监听开关、权限诊断页、模拟来电、提醒记录（全部/待确认/已确认）、恢复待确认、清空已确认记录。
- **厂商保活指引**：小米 HyperOS、OPPO、vivo、荣耀/华为、原生 Android 的设置路径。
- 纯本地：SharedPreferences + JSON，无网络、无账号、无第三方分析。

## 构建

环境要求：JDK 17、Android SDK Platform 35、Build-Tools 35.0.0。

```bash
cd android-app
./gradlew assembleDebug
```

如果 Gradle 下载慢，`gradle/wrapper/gradle-wrapper.properties` 已指向腾讯云镜像；依赖仓库在 `settings.gradle.kts` 中优先使用阿里云镜像。

因为工程位于含中文的目录，`gradle.properties` 中开启了：

```properties
android.overridePathCheck=true
```

如果后续遇到路径相关的构建异常，建议把工程移动到纯英文路径（例如 `C:\AndroidProjects\ImportantSmsSentinel`）后重新构建。

## 安装

```bash
adb install -r 重要短信哨兵-v1.4.1-debug.apk
```

或直接把 APK 发到手机安装（需允许“安装未知来源应用”）。当前为 debug 签名，适合个人/内部测试分发。

APK 输出位置：

```text
android-app/重要短信哨兵-v1.4.1-debug.apk
```

## 首次使用

1. 打开 App，进入“适配与权限”。
2. 授予**短信接收权限**和**通知权限**（必要）。
3. 授予**全屏来电提醒**（Android 14+ 为特殊访问；缺失时降级为高优先级通知）。
4. 授予**悬浮来电横幅**（“显示在其他应用上层 / 悬浮窗”）；这是在其他 App 和桌面顶部弹出胶囊所必需的。
4. 授予**精确定时**（可选；缺失时提醒可能延迟）。
5. 点“厂商保活设置”，按提示打开**自启动、后台运行、省电无限制、锁屏通知**。
6. 在“设置 → 短信过滤”确认关键词，默认 `会议,开会,参会,议程,会场`。
7. 设置页的“后台监听服务”应显示**运行中**；状态栏会有一条低优先级“正在监听”通知。
8. 点击“模拟一次来电”验证界面、铃声、震动、接听/挂断。
9. 让目标号码（默认 `10650821192421`）真实发一条含“会议/开会”的短信做端到端验收。

如果更新后仍然只有第一次能弹，请重点检查：厂商是否把 App 的“自启动”关掉、是否把“后台监听服务”通知隐藏或强制停止、电池策略是否为“无限制”。

## 关键限制

- **短信权限上架政策**：Google Play 对 `RECEIVE_SMS` 有严格限制，非默认短信应用可能无法上架。当前定位为个人/内部侧载。
- **全屏提醒**：Android 14+ 对 `USE_FULL_SCREEN_INTENT` 有资格限制，需用户在系统设置中授权；小米等厂商可能仍需额外“锁屏通知/通知亮屏”设置。
- **精确定时**：Android 12+ 需用户授权 `SCHEDULE_EXACT_ALARM`；缺失时提醒时间可能延迟。
- **系统强停**：用户在系统设置中“强行停止”App 后，短信广播和闹钟可能无法恢复，需重新打开 App。
- **厂商冻结**：前台监听服务能降低被冻结的概率，但不能保证绕过小米/OPPO/vivo 的省电策略；必须在系统设置里允许自启动和后台运行。
- **关键词过滤**：默认只提醒包含“会议/开会/参会/议程/会场”的短信；其他 OA 公文不会来电。需要全部提醒时可在设置中关闭过滤。
- **来源号码可伪造**：本应用只做号码匹配，不验证发送方身份，也不替代 OA 签收。
- **真机验证**：已在 Android 15（API 35）模拟器验证 V1.1：关键词过滤（非会议短信 0 条任务、会议短信生成任务）、前台服务运行、后台锁屏全屏来电、接听/挂断、记录恢复、精确闹钟、通知降级、应用内顶部横幅。小米 HyperOS / OPPO / vivo 等厂商真机仍需按设计文档 T01–T16、U01–U09 验收。
- **Android 15 CallStyle 限制**：没有全屏 Intent 时使用 CallStyle 会抛出 `IllegalArgumentException`，因此全屏不可用时自动改用普通高优先级通知（带接听/挂断动作），不再使用 CallStyle。
- **Android 15 edge-to-edge**：targetSdk 35 下已统一处理系统栏 inset，避免状态栏压住页面内容。
